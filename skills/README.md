# IVA Skills Ecosystem (AIVA Skills)

This directory hosts the unified native skills, external MCP adapters, and multi-platform distribution engines of **IVA**.

## 10 Operational Categories

1. **Core Intelligence & Reasoning**: Sequential thinking, Context7 doc resolution, Clean code refactoring.
2. **Quantitative Finance & Algorithmic Trading**: Hawkes point processes, MLOFI microstructure, SSVI volatility surface calibration, backtesting integrity, pre-trade gates.
3. **Media Studio, Video Directing & Omnichannel Social**: Autonomous video montage rendering, 13-skill Instagram growth suite, universal 7-platform social adaptation.
4. **Browser Automation & Web Operations**: Playwright sessions, Chrome DevTools Protocol, DOM inspection.
5. **Mobile & Device Testing**: Maestro mobile test automation, Android/iOS runner, screenshot framing.
6. **Cloud Deployment & Infrastructure**: Google Cloud Run, Firebase hosting & functions, Docker security sandbox.
7. **Engineering Hygiene & Workflow Mastery**: GSD Spec-Driven Development suite, Ponytail lazy senior dev, CodeRabbit automated review.
8. **Gemini API & Multimodal Tooling**: Gemini Live WebSocket streaming, structured output schemas, prompt engineering.
9. **Research & Deep Evidence Synthesis**: Autonomous deep research, fan-out web search, citation ledgers.
10. **System, OS & Storage Stewards**: Safe filesystem operations, Windows PowerShell reliability, GonkaRouter multi-model LLM pool, Omega persistent memory.

## Dynamic Autonomous Routing & Execution

IVA includes the `AutonomousSkillRouter` (`agents/IVA/ecosystem/autonomous_skill_router.py`), which scores incoming intents, selects the best-fit skills dynamically, composes multi-skill pipelines, and injects optimal tool railings into specialist executions on-the-fly.

See the full specification and tool schemas in [`IVA_SKILLS_MANIFEST.md`](../IVA_SKILLS_MANIFEST.md).
